
# 1. Cestas de 3 e 2 pontos

- A IA deve saber diferenciar, utilizando as linhas pintadas na quadra e o posicionamento do jogador ao arremessar, quando é 2 pontos ou 3 pontos.

# 2. Lances Livres (1 ponto)

- A IA deve identificar em que momento o jogador esta cobrando uma falta.
- Também é necessário uma validação para lances onde o jogador sofre a falta e ainda contabiliza os 2 pontos (And-One).
